## LinkedIn

I’m releasing Jevry: a desktop browser you can give tasks to.

In this real-time clip, it plays the final moves of 2048 and reaches “You Win.” The page reports 20,708 points in 1,013 moves, with no powerups used.

The game is one example. Jevry also works through supported website controls and researches sources with linked citations. You can watch its actions, stop it, or send a correction while it works.

Under the hood: a text model handles planning and conversation, Jev selects actions, and the desktop controller executes them through Chromium. Numeric games use local tile recognition and bounded forecasts.

It’s an MIT-licensed developer preview. You’ll need a text-model connection and a TypeSafe Jev key; provider usage may cost money. macOS is the verified runtime so far. The clip shows an earlier interface, and one win isn’t a general benchmark.
